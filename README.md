# language-learning-visualization

## Getting started

You need [Node.js](https://nodejs.org) version 20.19+ or 22.12+.

The app is in the `language-visualization` folder. To install its dependencies and start the dev server, run:

```bash
cd language-visualization
npm install
npm run dev
```

Then open the local URL shown in the terminal, usually http://localhost:5173. The page updates when you save a file.

## Other commands

Run these from the `language-visualization` folder:

| Command           | What it does                                  |
| ----------------- | --------------------------------------------- |
| `npm run build`   | Type-checks and builds the app into `dist/`   |
| `npm run preview` | Serves the production build locally           |
| `npm run lint`    | Runs the linter (Oxlint)                      |
